# CHRONOS // 5100     demo= https://1nam.github.io/5100/

A small Halloween web project inspired by the internet legend of a time traveler using an IBM 5100 computer.

The page is a futuristic terminal where visitors can ask questions and receive cryptic responses from the traveler.

Created with help from Duck.ai.

## How to Use

1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Type a question into the terminal.
4. Press **Enter** to send it.

Try asking about:

- IBM 5100
- Time travel
- The future
- War
- Dates
- The machine

## GitHub Pages

To publish the page:

1. Open the repository on GitHub.
2. Go to **Settings → Pages**.
3. Select **Deploy from a branch**.
4. Choose the `main` branch and `/root` folder.
5. Save the settings.

GitHub will provide a public website link.
